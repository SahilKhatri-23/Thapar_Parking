Camera nodes

Any camera can feed the system: ESP32-CAM, IP/CCTV (RTSP), a USB webcam, or a phone running the app in Camera-node mode.

How to connect

Phone as camera

Sign in on the app as guard/admin → More → Phone camera node. Pick “Gate ANPR” or a parking lot. Keep the phone on a stand; it uploads a frame every few seconds.

ESP32-CAM

Flash esp32cam/esp32cam_uploader.ino, set Wi-Fi, server and the camera key below. It POSTs JPEG frames to:

POST {{server_url}}/api/cameras/ingest/
X-Camera-Key: <key>
Content-Type: image/jpeg
IP camera / RTSP / USB webcam

Run the worker on this computer:

python manage.py camera_worker --key <key> --source rtsp://user:pass@192.168.1.20:554/stream --interval 3
# USB webcam: --source 0
# Android "IP Webcam" app: --source http://PHONE_IP:8080/video
